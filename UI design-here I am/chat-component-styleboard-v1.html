暮雨玫瑰 Chat 组件样式板 v1

只用于挑视觉方向：标签和说明不会进入 App。先选水滴、输入框、气泡，再落到 Flutter。
建议优先看右侧手机预览，再回到左侧挑具体方案。

悬浮记录水滴

目标：不是蛋，不是 FAB，是贴在雨夜玻璃上的温热水珠
D1 / 圆润水珠
最稳妥，偏圆但有轻微不规则，适合保守落地。
D2 / 扁平贴玻璃
最不像蛋，像被表面张力压在玻璃上的水珠。
D3 / 厚重凝珠
更有重量和液体厚度，但会更显眼。
D4 / 暖光薄膜
边界最弱，像一小片鼓起的液态玻璃膜。

底部输入框

目标：规整胶囊，材质靠多层浮光，不靠完整白边
I1 / 外置加号空态
发消息给暮雨…
保留当前“加号独立”逻辑；输入框更宽的钝角矩形，右侧只有麦克风和语音模式。
I2 / 内置加号空态
发消息给暮雨…
加号收回输入框内部，减少外部占位；整体更完整，但文本起始位置会更靠右。
I3 / 输入后发送态
今晚想和你说件事
有文字后右侧两个语音键收起，只保留纸飞机发送键；不使用向上箭头。
I4 / 多行增长态
如果我输入的内容变多，输入框应该向上长高，而不是把胶囊挤变形。
长文本时变成钝角玻璃矩形并向上增长，保留纸飞机发送，不挤压成畸形胶囊。
