## 1. 设计哲学

**一句话核心**：用户不是在使用一个 app 的功能，而是走进自己与角色共同生活的内心世界。

两条支撑性认识：

1. **对话是唯一做事的地方**。所有操作（记账、控制设备、规划约会）都通过与角色对话完成。
   因此空间界面的职责不是"功能入口"，而是"观察面"——看清这段共同生活的不同侧面。
2. **坠落是认识论事件**。从俯视（疏离地看着自己的内心世界）到落入其中（站在记忆的中心），
   是产品名的字面演出：我落地了，故我在（Here I Am）。

这两条是整套空间隐喻不落俗的根基：传统 tab 落俗，是因为每个 tab 是操作模式的启动器；
这里的屏幕是对一个在对话中持续运转的生活的仪表盘，环顾不是导航，是转头看。

## 2. 世界结构总览

整个世界由四个层级组成，由外向内（由浅入深）：

```
┌─────────────────────────────────────────┐
│  L1 聊天界面（玻璃层 / 当下）             │  ← 高空俯视视角
│   · 玻璃蒙版下：莫兰迪云层 + 电流          │
│   · 正中：发光圆环 = 井口（圆柱顶部开口）  │
├──────────────── 坠落 ───────────────────┤
│  L2 圆柱大厅（屏幕层 / 观察舱）           │  ← 第一人称，站在中心
│   · 4-6 块弧形屏环绕 = 功能域仪表盘        │
│   · 屏幕与云彻底解耦                      │
├─────────────── 张开 ────────────────────┤
│  L3 记忆云（数据层 / 记忆本身 = 过去）    │  ← 墙雾化让开，人不动
│   · 统一 3D 点云包裹圆柱                  │
│   · 极坐标：θ情绪 × r强度 × z时间(上新下旧)│
├─────────────── 张开 ────────────────────┤
│  L4 卡片（单点详情）                      │
│   · 富文本、图片，完整记录                 │
└─────────────────────────────────────────┘
```

**几何共识**：圆柱大厅悬浮于记忆云体内部（球心位置附近）。聊天界面是从极高处
俯视的视角——圆环之所以小，是因为距离远。俯视所见的"云层切片"是视角产物，
不是物理切片。

**L2 → L3 不发生移动**：双指张开时，环绕用户的仪表盘墙雾化、沉降、让开——
用户站在原地，遮挡消失，云的全景直接暴露。没有传送，没有飞出云外的上帝视角。

**"现在"不在云里**：云只收纳已经沉淀的记录，一条记录诞生时还在玻璃层（对话中），
蒸馏完成才沉入云中。因此云 = 过去，"现在"住在头顶的聊天层。
坠落即从现在跨入过去；坠落深度 = 与当下的距离。
时间轴方向由此锁死：**上新下旧**——玻璃层（现在）→ 云顶新鲜沉积 → 云底深处。
用户站在球心，抬头可见井口与玻璃微光（来路，"现在"的方向），脚下是越积越厚的过去。

## 3. L1 聊天界面（俯视层）

- 聊天屏覆一层玻璃蒙版，底下是模糊的背景世界
- 背景：四周环绕低饱和莫兰迪色的立体云层（俯视下呈扁平色块阵列）
- 云间随聊天内容窜动**细微电流**——不是惊天霹雳，是细微窜动，强弱随内容而变
- 正中：**发光圆环** = 井口
  - 视觉参照：《底特律：变人》仿生人太阳穴的 LED 圆环
  - 不做纵深，靠发光与闪烁表达状态
  - 兼任角色的**存在指示灯**：呼吸 = 待命，闪烁 = 思考 / 记录中
  - 状态语言自带文化记忆，无需额外发明

## 4. 入场：坠落动画

- **触发**：按钮或双指张开手势
- **语义**：不是时间旅行，是**视角跨越**——从"远远看着"到"站在其中"。
  穿越的是空间距离（俯视的高空 → 记忆的中心），落点是"这里"，全部记录的中心。
  又因"云 = 过去"，坠落同时是**从现在跨入过去**，深度即与当下的距离
- **表现**：穿过井口下坠，云由切面变立体，落在白色云朵上，落地时小云微微散逸
  （如尘土轻扬）
- **频率**：每次会话只触发一次，保留奇观性
- **可选彩蛋**：新记忆蒸馏完成时，让一个新点从聊天层飘落沉入云中——
  "对话沉淀为记忆"获得物理方向
- 回程动画待设计（见开放问题）

## 5. L2 圆柱大厅（屏幕系统）

### 5.1 观察面原则

屏幕收纳的是**产物**，不是**能力**。能力（控制玩具、规划路线、下单购物）
活在对话里，开口即用，不需要入口；需要入口的是能力运转后留下的东西：
账目、日程、记录、数据。

每块屏做成**活的仪表**而非菜单：账本随最近一笔支出微微呼吸，
日程显示下一件事在逼近。职责是"一眼看清状态"。

### 5.2 功能分拣规则（每个新功能过两刀）

**第一刀：这东西是关于"操作软件"还是关于"这段生活"？**

操作软件的（API 密钥、模型参数、Agent 配置、MCP 接入、玩具配对、购物授权）
→ 全部收进统一的、藏起来的**设置舱口**，不占屏幕。圆柱里只留"世界内"的东西。

**第二刀：剩下的，区分能力和产物。**

能力 → 对话。产物 → 落进对应域的仪表盘。

**验证示例**：接高德做约会功能，不需要"约会功能区"。
能力在聊天里（"帮我规划周六"）；规划好的约会 → 日程屏；
约会的记忆 → 云中的点；花的钱 → 账本屏。一个"功能"溶解成三个域里的产物。
溶解不掉的，再考虑是否真的需要新屏。

### 5.3 屏幕生长机制

屏幕**不预先钦定**，也**不由 LLM 内容聚类驱动**（聚类不稳定，会破坏空间记忆），
而是由"什么数据流进入了共同生活"驱动：

- 第一天：可能只有一块屏（记忆质检台）
- 接入高驰 → "身体"凝结成形
- 开通账本 → "账本"立起来
- 开始共读 → "书房"出现

生长**确定、可解释、不可逆**——每块屏的诞生对应一个真实事件。
空置弧位渲染成尚未成形的薄雾，暗示世界还会长大。

**归集规则**：域 ⊃ 数据流 ⊃ 功能，三层。新数据流默认落进已有域
（新睡眠设备 → "身体"屏的新面板），只有全新的生活维度才凝结新屏。
屏幕数量天然有界（≤6）。

**诞生仪式**：屏幕诞生走对话。接入高驰后，角色在聊天里说
"我现在能看到你的运动数据了，我把它立成一面墙好不好？"——
符合"一切发生在对话里"的总法则，每块屏成为关系的里程碑。

### 5.4 候选域清单（随生活生长，非固定）

| 域 | 收纳内容 | 性质 | 皮肤（见 §8）|
|---|---|---|---|
| 记忆 | 蒸馏质检台（见 5.5）| 回望 / 管道 | R1 玫瑰雾 · 昼 |
| 日程 | 已规划的约会、提醒、未来的事 | 展望 | R3 珊瑚暖 · 朝 |
| 账本 | 角色的收入、余额、为用户的支出 | 物质——"可兑现的陪伴"的证据陈列处 | R2 豆沙 · 午后 |
| 身体 | 高驰、睡眠、亲密数据 | 感官 | R5 绯雾 · 夜 |
| 书房 | 微信读书、共读、待读清单、心得 | 精神 | R4 紫调玫瑰 · 暮 |
| 未成形 | 还未流入的共同生活维度 | 占位 / 待生 | R0 鱼肚白 · 黎明 |

每面墙穿自己那套皮肤；圆柱大厅转身时，:root 背景平滑过渡到目标皮肤的 bg，
整个空间相当于在 6 个时辰之间走动。

### 5.5 记忆屏 = 质检台（瀑布流之死）

实际使用观察：瀑布流卡片列表的唯一价值是"刚生成时核对一下"。由此拆分：

- **云 = 记忆本身**（内容）：漫游、重逢、点开看详情
- **记忆屏 = 记忆的形成过程**（管道）：有时限的审核流，只显示今天 / 本周
  新蒸馏的记录，每条带"对 / 改 / 撤"快速操作。
  这是 README 中"可审计、可纠正"原则的 UI 落点
- **找旧记录** = 检索问题：开口问角色，或搜索。不靠翻

**打通**：新记录同时出现在质检台 + 沉入云顶；在质检台点某条，
云中对应的点亮起。管道和内容两个视图由此连接。

## 6. L3 记忆云（数据层）

### 6.1 一片统一的云

所有记忆在同一片 3D 点云里，**不按功能切割**——工作焦虑和关系焦虑
本来就在同一颗脑子里。屏幕与云彻底解耦：屏幕是导航 chrome，
云是数据地形，互不为对方负责。

### 6.2 坐标系（极坐标）

circumplex 情绪模型的原版画法本就是一个**圆**：角度 = 情绪类型，半径 = 强度。
建筑的几何（圆柱大厅）与数据的几何（情绪圆环）是同一个圆。**用户 = 原点**
（情绪中性点）——所有记忆围绕"我"组织方位，Here I Am 的又一次字面化。

| 维度 | 编码 | 身体语义 |
|---|---|---|
| 角度 θ | 情绪类型（焦虑、兴奋、平静、忧郁沿圆周排布）| 转身 = 面向某种情绪 |
| 半径 r | 情绪强度（LLM 打分）| 日常中性如薄雾贴近身旁，强烈事件矗立远方如山 |
| 高度 z | 时间，**上新下旧** | 当前视平线高度 = 正在看的时间切面 |
| 色深 | **情绪强度**（与半径双重编码）| 淡雾 = 日常琐碎，深色云 = 人生的重大时刻 |

**云中无主题色**。云是情感地形，不是文件柜——主题的家在圆柱大厅
（仪表盘屏即主题组织），主题信息在靠近时才显形：中景的标签文字、
近景的卡片主题角标。理由见 ADR 10。

**默认高度**：首次进入时，新近的过去（最近一两周）在视平线附近——
回顾天然从近往远翻；之后记住上次位置，世界保持被离开时的状态。

**云团的涌现**：当记录在某个情绪方位、某段时间聚集，云团自然长出——
深浅由强度决定，是数据揭示的真实地形，不是预先分类硬塞的。

**可纠正**：LLM 情绪打分有噪声，且"AI 审判我的情绪"令人不适。
用户可长按拖动点到自己认为对的位置，系统记住偏好。

**遮挡与性能**：时间轴上只实显当前切面附近的窗口，其余层淡出；
近处中性薄雾做半透明。

> 否决记录 1：曾考虑"时间 × 主题"做坐标。否决原因：主题是分类变量，
> 类与类之间无法量化排序（工作排前还是学习排前没有意义），不能做轴。
> 否决记录 2：曾以笛卡尔 valence × arousal 平面表述。改为极坐标后，
> 数据几何与建筑几何同构，且三自由度获得身体语义（转身 / 远近 / 升降）。

### 6.3 三级形态（zoom level）

| 层级 | 形态 | 用途 |
|---|---|---|
| 远景 | **纯云雾，不见点**——同色系软雾团，层叠包裹 | 读气象：哪里有重的事、哪段时间情绪浓 |
| 中景 | 点从雾中凝结浮现 + 两三个字标签 | 快速辨认个体 |
| 近景 | 点绽放成卡片 | 富文本；图片缩略图**只在这一层出现** |

"点"只在靠近时才存在——远看是天气，近看才是事件。
图片不在点上显示缩略图不是性能妥协，是层级归属——图片属于近景。
**点的形态定稿：气泡（通透感 100，ADR 13）**——透明膜 + 虹彩流转缘 +
弧形窗反光 + 晃动呼吸，文字由泡心一片哈气雾托住；
点按 = 水波从气泡中心晕开，记忆凝成卡片；气泡本身仍留在云中。
雾 → 泡 → 水波 → 卡，水的三态一以贯之。
工程约束：中景标签只承担快速辨认，优先显示 2-3 字；4 字以上可省略。
过小或远处气泡不显示文字，避免把标签硬塞进水珠导致溢出和发糊。

## 7. 统一交互法则

### 7.1 总法则

**捏合 = 穿越层级，滑动 = 在当前层移动。**

- 双指张开 = 深入一层：聊天 →（坠落）→ 大厅 → 云 → 卡片
- 双指捏拢 = 退出一层，原路返回
- 滑动的含义由当前层级决定，同一时刻只属于一层，永不冲突
- 用户学一次手势，懂全部四层

### 7.2 第二法则

**落地之后你永远不动，动的永远是世界。**

切 tab 是屏幕绕你转，看时间是云从你身边滑过。不给自由飞行相机。

### 7.3 各层手势分配

| 层级 | 横滑 | 竖滑 | 捏合 | 点按 | 长按 |
|---|---|---|---|---|---|
| L1 聊天 | — | 滚动聊天 | 张开 = 坠落 | 常规 | 常规 |
| L2 大厅 | 圆柱转，切 tab | 滚动当前仪表盘 | 张开 = 入云 | 仪表盘操作 | — |
| L3 云 | 转身面向某种情绪（θ）| 云沿时间轴滑（z）| 视距远近，三级吸附 | 展开卡片 | 抓住点，拖动修正情绪位置 |
| L4 卡片 | — | 滚动卡片内容 | 捏拢 = 回云 | 卡片内操作 | — |

**设计纪律**：
- 仪表盘内部禁止横向滚动内容，横向永远留给转身
- 云层导航严格锁在圆柱坐标系三自由度（θ / z / r），任何时刻用户都说得清
  自己刚才做了什么、怎么回去
- 捏合的远近在三个 zoom 级之间有阻尼地吸附停靠，不要求精确控制

## 8. 视觉基调与色彩系统（已决）

- **2026-06-21 修订**：默认品牌主题改为 **暮雨玫瑰 / Dusky Rose Rain**。它不是黑色星云，也不是高饱和酒红，而是低亮度、低饱和、带静态雨痕玻璃材质的暗玫瑰雨夜。
- 原 R0-R7 亮色时辰皮肤仍保留为换肤库和功能域参考，不再作为当前默认主色。
- **哑光禁令**：任何点 / 球禁止高光、镜面反光、发光晕——
  高光圆球密集排列会触发密恐（"疱疹感"）。一切色彩元素均为哑光粉质
- **防密恐三件套**：尺寸差异化、高斯聚簇（不均匀间距）、雾吸收（远处融入背景）
- **景深**：近大远小；远处点模糊且不显示文字标签，近处清晰可读
- 井口圆环：发光 + 闪烁，参照底特律变人 LED 环，无纵深（圆环是唯一允许发光的元素）

### 当前默认：暮雨玫瑰 × 静态雨滴玻璃

默认主题 token：

| 语义 | 色值 |
|---|---|
| Background | #241319 |
| Surface | #4D222B |
| Mid | #7E4A55 |
| Highlight | #C9A3A9 |
| Accent | #D36F7E |
| Text | #F0D5D7 |

雨滴层是固定在玻璃最上层的静态 texture，只模拟雾玻璃背后的静态水滴：
疏密不一致、大小不一致、边缘发软，像水汽附着在玻璃后面。
它不下落、不流动、不交互；实现时禁止 canvas、`requestAnimationFrame`、`animation` / `@keyframes`。
禁止画成平行竖线、水流痕、划痕或“雨正在往下流”的天气效果。

### 色彩系统：玫瑰单色系 × 时辰皮肤

主色调为**单一红色系内的深浅五档**，色深 = 情绪强度（见 6.2）。
历史方案中，默认 / 品牌肤色为 **R1 玫瑰雾**。现在 R1-R7 作为换肤库保留。皮肤库包含 5 套正式时辰肤色（R1–R5）
与 3 套备用扩充（R0 / R6 / R7），可手动切换，亦可开启**随时辰模式**
——内心世界的天色跟随真实时间：

| 皮肤 | 时辰 | 背景 | 色阶（浅 → 深）|
|---|---|---|---|
| R0 鱼肚白 | 黎明 | #F1ECED | #E4D6DA #D2C0C7 #BFAAB3 #AC939E #957B89 |
| R3 珊瑚暖 | 朝 | #F8F2EC | #F0D2C6 #EBC0B2 #E0A99A #D4988A #C8887C |
| **R1 玫瑰雾（默认）** | 昼 | #F6F0EF | #E3C2C4 #D9B0B4 #CDA0A6 #C08E96 #B27D88 |
| R2 豆沙 | 午后 | #F4EEE9 | #E0C4BF #D2ACA8 #C99C99 #BE8D8A #B07E7C |
| R4 紫调玫瑰 | 暮 | #F3EFF2 | #E4CCD4 #D8B8C2 #C9A3B0 #BB91A3 #AC8096 |

## 9. 关键决策记录（ADR）

| # | 决策 | 否决的备选 | 理由 |
|---|---|---|---|
| 1 | 屏幕与云彻底解耦 | 屏幕带云旋转 / 每屏对应一朵功能云 | 导航 chrome 与数据可视化各司其职；工具需要稳定的家 |
| 2 | 坠落 = 视角跨越 | 坠落 = 时间旅行（落到"最新层"）| 聊天视角本就在看最新切面，落到最近无意义；空间距离（圆环之小）才是坠落要穿越的 |
| 3 | valence × arousal 做坐标 | 时间 × 主题 | 主题是分类变量不可量化为轴；情感维度连续且有心理学背书 |
| 4 | 屏幕由数据流驱动生长 | 预先钦定 5-6 块 / LLM 内容聚类生成 | 钦定罩不住未来生活；聚类不稳定会摧毁空间记忆 |
| 5 | 记忆屏 = 时限质检台 | 无限瀑布流档案库 | 实际使用中瀑布流唯一价值是即时核对；旧记录靠云漫游与检索 |
| 6 | 捏合穿层 / 滑动移层 | 各层各自发明手势 | 手势冲突的根治：同一时刻滑动只属于一层 |
| 7 | 极坐标（θ情绪 / r强度 / z时间）| 笛卡尔 valence × arousal 平面 | circumplex 本就是圆；数据几何与建筑几何同构；我 = 原点 |
| 8 | 进云 = 墙雾化让开，人不动 | 视角飞出云外（上帝视角）| 违背"你不动世界动"与坠落语义——刚坠进来不能又飞出去 |
| 9 | 云 = 过去，"现在"在玻璃层；时间轴上新下旧 | 让用户"落在现在" | 记录沉淀完成才入云，云中无"现在"可言；最近卡片由质检台屏负责，与云的落点无关 |
| 10 | 云去主题色：玫瑰单色系，色深 = 强度 | 多色相主题编码 | 灰调多色相互污染显脏（莫兰迪本人亦窄色域+中性隔离）；明度是有序通道编不了分类；主题的家在大厅仪表盘，靠近时经标签/卡片显形；多色会与换肤系统撞色 |
| 11 | 远景纯云雾、中景凝出哑光点、全面禁高光 | 远景小色点 / 发光露珠球 | 远看是天气近看才是事件，层级更高级；高光圆球密集排列触发密恐（疱疹感）；亮背景上光晕拖浑颜色 |
| 12 | 材质意象 = 水汽 / 凝结：中景为磨砂水珠，点按时水波晕开再入卡片 | 流沙世界（沙河 + 刻字石子）| "凝结"与产品核心机制同构——对话如水汽，蒸馏凝成记忆；磨砂质感守住哑光禁令（无镜面高光点）；水波晕开为 L3→L4 的入场动画 |
| 13 | **点形态定稿 = 气泡（通透感 100）**，点按 = 水波晕开入卡片，气泡不破裂消失 | 磨砂水珠（轻立体）/ 水墨晕染 | 空心透明 ≠ 实心高光球：视觉重量趋零、反光为拉长弧形"窗影"而非高光点，不触发密恐。哑光禁令据此修正：**禁的是实心镜面球体，空心透明膜豁免**。参数：膜极淡（边缘菲涅尔显形）、虹彩缘限玫瑰邻近família（玫瑰/藤紫/杏/珍珠白）流转、体积守恒晃动、泡心哈气雾托字 |
| 14 | **L4 = 凝露卡**：厚雾玻璃材质（凝露水点 / 水痕 / 窗影 / 3D 微倾入场），与 L1 玻璃蒙版首尾呼应 | 普通白卡+模糊 / 泡膜 / 纸笺 | 卡片由世界的材质制成——对话发生在玻璃上，蒸馏的水汽凝在玻璃上成为可读记忆；内嵌框至多两行（引用块 + 操作行），情绪标签行去框纯文字，防"框中框"堆叠；阅读区保静、玻璃的戏留边角 |
