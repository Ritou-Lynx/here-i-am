# Here I Am UI System Spec

本文档是第一步产物：把当前视觉方案整理成可复用的 UI 规则。它面向后续 Flutter 落地，不讨论完整叙事，只保留可以执行的设计约束。

## 1. 分层使用范围

### 世界层

用于用户与角色、记忆、生活空间直接相处的地方。

包括：
- 聊天主页
- 坠落 / 回程
- 圆柱大厅
- 记忆云
- 凝露卡
- 记忆沉淀提示

允许：
- 玻璃、雾、水汽、气泡、水波、轻 3D。
- 低声量动效。
- 空间隐喻和情绪化状态。

### 产品层

用于展示共同生活留下的产物。

包括：
- 记忆质检台
- 日程
- 账本
- 身体
- 书房
- Personal / Review 中的生活内容

允许：
- 使用世界层的色彩和材质。
- 使用仪表盘式组件。
- 使用轻微呼吸、进入、完成、归档动效。

限制：
- 不把每个功能都做成独立梦境。
- 不牺牲列表扫描、状态判断和操作效率。

### 系统层

用于管理软件本身。

包括：
- 设置
- 模型配置
- API key
- 权限
- 备份
- 调试
- 设备授权

允许：
- 使用同一套色彩、字体、间距。
- 入口可以叫“设置舱口”。

限制：
- 内部使用清楚的列表、表单、开关、说明。
- 不使用坠落、水波、圆柱大厅作为主交互。

## 2. 色彩规则

### 当前默认主题（2026-06-21 修订）

默认品牌肤色从原 R1 玫瑰雾切换为 **暮雨玫瑰 / Dusky Rose Rain**。
这是一套低亮度、低饱和的暗玫瑰雨夜主题，叠加静态雾面玻璃雨滴材质。
原 R0-R7 亮色时辰皮肤保留为换肤与功能域参考，不再作为当前默认主色。

核心 token：
- Background：`#241319`
- Surface：`#4D222B`
- Mid：`#7E4A55`
- Highlight：`#C9A3A9`
- Accent：`#D36F7E`
- Text：`#F0D5D7`

### 基调

- 当前默认是暮雨玫瑰暗色雾面基调，不做高亮黑色星云。
- 背景低饱和、低对比，避免夜店红、酒红霓虹和黑色星云感。
- 玻璃、雾、雨滴只作为材质，不能抢聊天和卡片内容。
- 主题不使用多色相编码；云中的色深只表达强度。

### 皮肤

| Token | 名称 | 背景 | 浅 -> 深 |
|---|---|---|---|
| R3 | 珊瑚晨 | `#F8F2EC` | `#F0D2C6` `#EBC0B2` `#E0A99A` `#D4988A` `#C8887C` |
| R1 | 玫瑰雾 | `#F6F0EF` | `#E3C2C4` `#D9B0B4` `#CDA0A6` `#C08E96` `#B27D88` |
| R2 | 豆沙 | `#F4EEE9` | `#E0C4BF` `#D2ACA8` `#C99C99` `#BE8D8A` `#B07E7C` |
| R4 | 紫调玫瑰 | `#F3EFF2` | `#E4CCD4` `#D8B8C2` `#C9A3B0` `#BB91A3` `#AC8096` |
| R5 | 绯雾 | `#F1EAE8` | `#DCBDB9` `#CBA3A0` `#B98A87` `#A87874` `#9A6B6B` |

### 语义色

先不增加复杂语义色。第一版只使用：
- Primary：当前皮肤第 4 档。
- Primary soft：当前皮肤第 2 档。
- Text strong：暖灰深色。
- Text soft：暖灰浅色。
- Surface：半透明白 / 皮肤背景混合。
- Danger / error：保留系统红，但降低饱和度。

## 3. 材质规则

### 玻璃

用于：
- 聊天层蒙版。
- 凝露卡。
- 轻浮层。

规则：
- 背景模糊要克制。
- 边缘可以有极淡白色内描边。
- 不能出现强镜面高光点。

### 静态雨滴玻璃贴层

用于：
- 暮雨玫瑰主题的最上层玻璃材质。
- 聊天背景、凝露卡和沉浸式观察面的湿润氛围。

规则：
- 雨滴不是动画，不下落、不流动、不交互。
- 不使用 canvas、`requestAnimationFrame`、`animation` 或 `@keyframes`。
- 只使用 CSS / Flutter 可等价实现的静态 overlay 与伪元素思路。
- 结构上固定为最上层非交互贴层：`position: absolute; inset: 0; pointer-events: none; z-index: 8;`。
- 只表达三件事：少量微小凝露点、雾面颗粒、顺着玻璃留下的细水痕。
- 透明度由 token 控制，默认值：`rainOpacity = .18`、`rainMicroOpacity = .10`、`rainStreakOpacity = .13`。

### 雾

用于：
- 背景世界。
- 尚未成形的屏幕。
- 远景记忆云。
- 卡片边缘气氛。

规则：
- 雾表达“还没有变成可操作对象”。
- 远景只看气象，不显示点和文字。

### 气泡

用于：
- 中景记忆点。

规则：
- 透明膜感。
- 允许极淡虹彩边缘。
- 文字由泡心哈气雾承托。
- 远处或过小气泡不显示文字。
- 标签优先 2-3 字，4 字以上省略。
- 气泡点按后不破裂消失。

### 水波

用于：
- L3 进入 L4。
- 记忆从点变为可读详情的瞬间。

规则：
- 水波从气泡中心晕开。
- 水波是“展开”而不是“爆炸”。
- 水波之后出现凝露卡。

### 凝露卡

用于：
- 记忆详情。
- 审核中的记忆详情。
- 未来也可用于重要生活事件详情。

规则：
- 厚雾玻璃。
- 边缘允许凝露 / 水痕 / 窗影。
- 阅读区保持安静，装饰留在边角。
- 避免多层框中框。
- 情绪标签行使用纯文字或极轻标记，不做厚标签堆叠。

## 4. 动效语义

| 动效 | 语义 | 使用场景 | 约束 |
|---|---|---|---|
| 呼吸 | 角色在场 / 待命 | Presence ring、活仪表 | 慢、浅、不中断输入 |
| 闪烁 | 思考 / 记录中 | Presence ring | 不做刺眼频闪 |
| 坠落 | 从当下进入记忆中心 | Chat -> Hall | 每次会话最多一次正式奇观 |
| 沉入 | 对话蒸馏为记忆 | 新记忆生成 | 轻量彩蛋，不阻塞聊天 |
| 雾化让开 | 从大厅进入云 | Hall -> Cloud | 人不动，世界让开 |
| 水波展开 | 点进入卡 | Bubble -> DewCard | 不是破裂，不是爆炸 |
| 凝结出现 | 记忆变得可读 | DewCard 入场 | 轻微 3D，避免炫技 |
| 收回 | 返回上一层 | Card -> Cloud 等 | 原路返回，减少迷路感 |

## 5. 字体与信息密度

### 字体层级

第一版沿用系统字体，不引入品牌字体。

- Page title：用于主要区域标题。
- Section title：用于仪表盘分区。
- Body：用于消息、卡片正文、设置说明。
- Caption：用于时间、来源、状态。
- Micro：用于短标签、方位、仪表刻度。

### 信息密度

| 区域 | 密度 | 规则 |
|---|---|---|
| Chat | 低 | 输入优先，装饰不能压消息 |
| Memory Review | 中 | 每条都能快速判断、修改、撤销 |
| Dew Card | 中 | 首屏读懂核心，详情可滚动 |
| Schedule / Ledger / Body / Study | 中 | 仪表盘扫读优先 |
| Settings | 高确定性 | 表单清楚，少装饰 |

## 7. 页面套用规则

### Chat

必须承载：
- 消息流。
- 输入。
- Presence ring。
- 记忆沉淀状态。
- 当前已有的聊天功能和显式点击入口。

不应该承载：
- 新增的大量功能入口。
- 设置项。
- 全屏复杂仪表。

第一版约束：
- 不用 3D 手势替代现有点击功能。
- 圆环、坠落、记忆沉淀可以作为视觉增强，但不能阻断聊天主流程。
- 任何新动效都必须有普通点击路径。

### Life Space

必须承载：
- 生活产物的观察面。
- Review / Schedule / Personal 的结构。

可逐步升级：
- 第一版保留点击切换。
- 第一版使用 2.5D 仪表盘。
- 后续验证圆柱大厅。

### Memory Review

必须承载：
- 今天 / 本周新蒸馏记忆。
- 对 / 改 / 撤。
- 来源可追溯。

不应该承载：
- 无限旧记录瀑布流。

### Settings

必须承载：
- 模型、权限、数据、调试、授权等软件事务。

不应该承载：
- 圆柱屏。
- 记忆云。
- 大型水波转场。

## 8. 禁止项

- 黑色夜空星云作为主基调。
- 实心高光球密集排列。
- 用多色主题色切分记忆云。
- 所有页面都使用沉浸式动效。
- 远处气泡显示长文字。
- 仪表盘内部横向滚动内容。
- 设置页过度世界观包装。
- 页面里散写一次性颜色、阴影、动效时长。

## 9. 第一轮落地目标

第一轮只做能支撑真实 App 的最小 UI 系统：

1. 色彩和材质 token。
2. Presence ring。
3. Dew card。
4. Memory review item。
5. Chat surface。
6. Settings hatch entry。

圆柱大厅、完整记忆云、复杂坐标系、坠落奇观进入后续验证。
