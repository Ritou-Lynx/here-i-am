# FlexNote MCP 接入速查

> **版本基准**：FlexNote 1.1.57（2026-10-04）。MCP 从 1.1.53（2026-09-18）开始提供，之后的发布说明里没有 MCP 相关变化。工具名来自 1.1.56 的工具清单。核对日期：2026-10-08。
>
> **依据标记**：
> - 【官方】官方博客或发布说明
> - 【实测】本项目 2026-10-02 由 Codex 在用户电脑上跑通（教综导入、初始化、5 题冒烟）
> - 【约定】本项目自己的用法
> - 【未核实】还没验证

## 1. 一句话

FlexNote 桌面端自带 MCP 服务，**只监听本机**，能检索和写入**当前打开的空间**：日记、笔记卡片、标签和属性、待办、白板。只能给电脑上的客户端用（Codex、Cursor、Claude Desktop），网页端和手机上的 AI 都连不上。

## 2. 开启与连接

| 项 | 内容 |
|---|---|
| 版本要求 | 专业版功能，需要登录有效会员账号【官方】。用户的终身版可以用【实测】 |
| 开启 | 设置 → MCP 服务 → 打开，然后复制对应客户端的配置【官方】 |
| 地址 | `http://127.0.0.1:39125/mcp`，只绑定本机回环地址，默认端口 39125【官方】 |
| 鉴权 | `Authorization: Bearer <访问令牌>`【官方】 |
| Codex | 设置页"Codex CLI"标签直接给出 TOML 配置，通过 stdio 桥接，需要环境变量 `FLEXNOTE_MCP_URL` 和 `FLEXNOTE_MCP_TOKEN`【官方】。原样粘贴即可【实测】 |
| 生命周期 | FlexNote 退出后 MCP 服务也停止【官方】。新版本增加了工具后，要重启桌面端，并在客户端里重新启用 MCP 或新开会话【官方】 |
| 令牌 | 只用于本机鉴权；在设置里重置后，旧配置失效【官方】。本项目 2026-10-02 曾因令牌出现在聊天截图里而重置过一次，令牌不要进入截图、聊天和仓库【约定】 |

Cursor / Claude Desktop 的配置示例【官方】：

```json
{
  "mcpServers": {
    "flexnote": {
      "url": "http://127.0.0.1:39125/mcp",
      "headers": { "Authorization": "Bearer <令牌>" }
    }
  }
}
```

## 3. 能做什么（官方按类别列出）

| 类别 | 能力 |
|---|---|
| 读 | 空间里的卡片、日记、白板、待办、标签、收藏；知识库检索；卡片全文、高亮和元数据 |
| 日记 | 按日期列出和读取；新建或追加（不给日期就是今天） |
| 卡片与标签 | 新建笔记卡、追加正文、加标签、设属性、管理收藏 |
| 待办 | 新建、修改、完成、删除 |
| 白板 | 列出白板和节点；新建便签、文本、形状、网页卡、媒体卡、分组、连线；读取布局和局部重排 |
| 界面 | 在 FlexNote 窗口里打开某张卡或某块白板 |

**只读模式**【官方】：
- 写入类工具要关掉只读模式才能用。
- 也可以分别关掉"新建""删除""白板"几类工具。
- 官方建议刚接入时先开只读。

## 4. 已知工具名（不是完整清单）

下表是 [`tools/flexnote_tutor/`](../../tools/flexnote_tutor/README.md) 用到的部分，名字已经对照 1.1.56 的工具清单核对过【实测】。完整清单当时只在聊天里给过，没有存进仓库。

| 工具 | 用途与要点 |
|---|---|
| `get_current_workspace` | 确认当前打开的是哪个空间。MCP 不能切换空间，切换只能在 FlexNote 界面里做 |
| `list_collections` | 侧边栏的收藏文件夹 |
| `list_whiteboards` | 白板列表。白板列表里的"文件夹"分组列不出来，只能按白板名找 |
| `list_whiteboard_entities` | 某块白板上的卡片和节点 |
| `list_tag_cards` | 按标签列出卡片 |
| `list_entity_cards` | 列出资料卡，例如 PDF 卡 |
| `search_knowledge` | 知识库检索。用短关键词，复合词拆开搜；`entityIds` 把范围限定在某些卡或 PDF；`whiteboardId` 限定在某块白板 |
| `read_card` | 读卡片，`ids` 可以批量读；PDF 用 `pageFrom`、`pageTo` 只读命中页附近 |
| `create_note_card` | 新建笔记卡 |
| `append_to_card` | 往卡片末尾追加内容 |
| `tag_card` | 给卡片打标签 |
| `set_card_property_value` | 设置属性值，`items` 可以批量设 |
| `create_tag`、`create_tag_property` | 新建标签；新建属性列，类型有 Date、Select、Text、Number、MultiSelect，可以批量建 |
| `create_whiteboard` | 新建白板 |
| `update_canvas_layout` | 重排白板布局。会改动用户的白板，本项目约定要先得到用户同意 |
| `append_to_daily_note` | 往今天的日记追加一行 |

**补全完整清单的办法**：在 Codex 里问"列出 flexnote 的所有工具及参数"，删掉输出里的令牌后，补进本节。

## 5. 限制与易错点

- **只作用于当前打开的空间**【官方】【实测】。读写之前先用 `get_current_workspace` 确认，不对就请用户在界面里切换。
- **白板操作要有白板 ID**；如果那块白板没打开，FlexNote 会自动打开它，等画布加载完再执行【官方】。
- **不能删除笔记卡**。官方列出的删除能力只针对待办【官方】，本项目也一直没找到删卡的工具【实测】。练习用的题卡要用户自己在界面里删。
- **MCP 做不了的事**【官方】：生成图片、在对话里弹确认、视频截帧和视频高亮。
- **只能本机用**：claude.ai、ChatGPT 网页版、手机上的 AI 都连不上。ChatGPT dot 只能用官方插件，接不了自定义 MCP【官方】。
- **任何拿到令牌的本机进程都能调用**；它不是团队网关，也没有公网访问【官方】。
- **检索**【实测】：
  - 用短关键词；没搜到不代表资料里没有。
  - 只在目录里命中，不足以支撑细节讲评。
  - PDF 先用 `search_knowledge` 定位，再用 `read_card` 按页读。
- **从 Obsidian 导入的卡片**，标题是原来的文件名，不是章节名【实测】。
- **点数**：语义检索和 OCR 走"智能索引"，会消耗点数，主要在建索引时消耗；关键词检索不消耗。终身版含 3000 点【约定，来自 2026-10-02 读到的官方资料】。

## 6. FlexNote 内置 AI（不经 MCP）

| 模式 | 能做什么 |
|---|---|
| Ask | 主要读数据：检索、问答、总结、比较、解释 |
| Agent | 可以新建或修改卡片、待办、标签、白板节点、连线和布局，必要时停下来请用户确认 |

- 两种模式都用你自己配置的模型服务：服务商、API Key、Base URL、模型名【官方】。
- 智能索引覆盖笔记、PDF、图片里的文字和媒体字幕【官方】。

## 7. 其他

- **平台**：Windows、macOS、Android、Web；iOS 还在开发中【官方】。
- **导入**：可以从思源经本地 API 导入，保留笔记本层级，重新导入时增量同步（1.1.48 起）；也可以导入 Obsidian【官方】。
- **导出**：可以导出 Markdown，附件一起打包【官方】。
- **页面外观**：支持自定义 CSS（1.1.20 起）；没有插件系统，也没有可自定义的首页【官方：发布说明中未见】。
- **图表**：支持 Mermaid，可以缩放和平移【官方】。

## 8. 在本项目里的角色

以 [个人数据中枢 ADR](../development/PERSONAL_DATA_HUB_ADR_20261005.md) 和 [总规划](../development/PERSONAL_DATA_HUB_PLAN_20261005.md) 为准：

- FlexNote 是"画图的窗户"，不存权威数据。
- 不把思源的内容整体搬进 FlexNote；只导入需要画图理解的主题。
- 教综资料在"求职"空间里。

使用方：[`tools/flexnote_tutor/`](../../tools/flexnote_tutor/README.md)，即 Codex 学习导师，学习目录是 `~/study`。按 2026-10-05 的 [教编规划](../development/handoffs/TEACHER_EXAM_STUDY_PLAN_20261005.md)，这条线以后不再用来记进度，只保留资料、用来看图；是否执行等用户确认。
