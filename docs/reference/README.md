## 一页对比

| | 思源 3.8.6 | FlexNote 1.1.57 |
|---|---|---|
| MCP 在哪 | 内核自带，免费 | 桌面端自带，专业版功能 |
| 地址 | `http://127.0.0.1:6806/mcp` | `http://127.0.0.1:39125/mcp` |
| 鉴权 | `Bearer <API Token>`；3.8.6 起支持 OAuth 2.1（PKCE，客户端需在思源里手动添加，不支持动态注册） | `Bearer <访问令牌>`；Codex 用 stdio 桥接加环境变量 |
| 能否远程接入 | 能：用 OAuth 加隧道或服务端部署，可接 claude.ai、ChatGPT 网页版（本项目未实测） | 不能：只绑定本机 |
| 作用范围 | 整个工作空间，包括所有笔记本 | 只有当前打开的空间，MCP 不能切换 |
| 删除能力 | 很大：笔记本、文档、块、数据库行和字段、附件、工作区文件、快照 | 只能删待办，不能删笔记卡 |
| 全局只读 | 没有 MCP 只读开关，靠暴露策略和客户端白名单收窄 | 有只读模式，还能分类关掉工具 |
| 结构化数据 | 数据库（属性视图）：建表、字段、行、单元格，16 种字段类型；不能用 MCP 建视图 | 标签加属性列（Date、Select、Text、Number、MultiSelect） |
| 检索 | 全文、语义（数据外发、计费）、只读 SQL、反链 | 知识库检索（关键词免费，语义耗点数） |
| 白板 / 画布 | 没有（思维导图块不经 MCP） | 有：节点、连线、分组、布局 |
| 外部访问 | 有 http_request、web_fetch、web_search（建议关掉） | 没有 |
| 本项目的用途 | 成篇文字、学习账本、招聘日历、只读看板文档 | 画图理解、PDF 和视频资料 |

## 怎么选

- **要长期保存、要按块链接、要建账本**：用思源。
- **要在画布上理清结构、对照 PDF 或视频**：用 FlexNote。同一份内容只在一处维护，不两边同步。
- **个人结构化数据**（规划、收支、睡眠等）以 i_core 为准，两款笔记工具都只是"窗户"，见 [个人数据中枢 ADR](../development/PERSONAL_DATA_HUB_ADR_20261005.md)。
- **要让网页端或手机上的 AI 直接读笔记**：只有思源可行（OAuth 加对外暴露），而且需要电脑开着。

## 安全底线

1. 令牌只放在环境变量里（`SIYUAN_API_TOKEN`，以及 FlexNote 设置页给的变量），不进文件、仓库、聊天和截图。
2. 思源要两道收窄：客户端白名单，加上思源自己的暴露策略。`file`、`repo`、`sync`、`bazaar`、`http_request` 这类工具不对 Agent 开放。
3. 删除类动作即使在白名单里，也由指令禁止，删除只由用户在界面里操作。
4. 接入 FlexNote 时先开只读模式；写入之前先确认当前打开的空间。
