# docs/design — 春雨昼眠主题

> **给接手的 Agent / 开发者：** 本目录是 Here I am **当前唯一主力** UI 设计方向「春雨昼眠」。
> 子目录 `archive/` 内的文档与图片是**已废弃的探索史**，**不是**现行设计，禁止据此写代码、引用色值或恢复 UI。
> 接手项目请先读仓库根 `AGENTS.md`；UI 实现只认下方「现行」清单。
