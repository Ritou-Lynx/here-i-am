# 春雨昼眠主题 · Memory Review

> 状态：列表与常用 PresentationModule 适配已落地。本文只约束 Memory Review 的列表卡片、间距与页面状态；记忆详情页暂不换皮。

## 页面关系

- 沿用生活空间的 `雨玻璃.jpg` 公共背景，不另加页面背景、顶部标题或介绍文字。
- 列表区域没有整页米白承载层，雨景直接出现在卡片之间。
- 页面级可读性由每张卡片自身解决，不修改、不压暗、不模糊背景。

## 卡片样式

- 卡片使用高浓度浅雾：暖灰白到浅灰绿的轻渐变，保持雨景透气但优先保证文字清晰。
- 卡片不使用背景模糊；边缘为细白线，阴影轻且向下扩散。
- 主文字使用近黑绿，次级文字使用灰绿色；强调色统一为苔绿。
- 时间放在卡片内部左上角，记忆类型放在右上角的小胶囊中，取消卡片外的独立时间标签。
- 日期固定使用绝对格式：当年为 `7月30日 21:14`，跨年为 `2025年7月30日 21:14`；不再混用“今天”“3天前”“7/30”等格式。
- `PresentationModule.title` 有值时作为可见标题，否则回退到 `dropletLabel`；`subjectRef` 作为标题下的对象/上下文；`statusLabel` 与实体完成/取消状态均使用小型状态胶囊。
- 卡片之间垂直间距为 14，页面左右留白为 16；不额外插入分组标题。
- 点击时使用很轻的缩放反馈，确认卡片可进入详情，但不增加按钮或箭头。

## 已识别的 PresentationModule

| 模组 | 真实字段 | 列表呈现 |
|---|---|---|
| `text` | `text`、`emphases` | 正文段落；强调词使用低浓度苔绿底纹。 |
| `quote` | `text`、`context` | 左侧苔绿细线、引用正文与上下文。 |
| `number` | `value`、`unit`、`note` | 大号数字、单位与自然语言说明。兼容旧卡的 `caption`。 |
| `table` | `rows[{label,value}]` | 紧凑两列键值表。兼容旧 prompt 的 `headers + rows[][]`。 |
| `sparkline` | `points`、`caption` | 归一化迷你趋势线及说明。 |
| `media` | `assetPath`、`kind`、`caption` | 图片缩略图；音频/视频显示类型占位与说明。 |
| `linkAttachment` | `url`、`title`、`source` | 来源标记、单行标题与“打开”。 |
| `progressBar` | `value`、`max`、`unit`、`label` | 进度条与数值；兼容旧卡只给 0–1 比例的写法并显示百分比。 |

Record Organizer 的生成提示统一使用 Dart 模型的 `type`、`note`、对象式 table rows 和显式 `value/max`，避免生成了数据但 UI 静默丢内容。

## 页面状态

- 加载、空列表和错误状态都只使用一块紧凑浅雾卡片，不铺满页面。
- 错误态提供明确的“重试”操作；空态保留可下拉刷新能力。
- 下拉刷新使用苔绿指示色与暖灰白底色。
