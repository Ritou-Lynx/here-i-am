# 春雨昼眠主题 · 统一阅读

> 状态：统一书架视觉已于 2026-08-02 确认并落 Flutter；小说阅读、漫画阅读及共读次级界面仍需单独确认。

## 产品边界

- 用户侧只保留一个「阅读」入口，把小说与漫画呈现在同一书架。
- 当前数据层仍沿用独立的 `Books` 与 `ComicMangas` 表和服务；首阶段统一界面，不伪装成已经完成数据迁移。
- 添加入口按真实能力分为「导入 TXT 小说」与「添加漫画链接」。

## 已确认的书架结构

- 顶部只保留「阅读」、同步状态和添加入口，不放介绍文字或大型「继续阅读」标题。
- 一级标签为「在读 / 全部 / 小说 / 漫画」；续读通过「在读」标签内的具体书目完成。
- 同一书架提供两种呈现方式：
  - 纯文字列表：标题、内容类型、作者或来源、阅读进度。
  - 封面排列：书籍或漫画封面、标题、章节或页数进度。
- 封面与列表只是同一份书架数据的两种视图，不拆成两个页面。

## 已确认的视觉

- 整张书架使用 `assets/images/雨玻璃.jpg` 全图铺底，不再使用 `spring_rain_glass_texture_raw.png`。
- 背景不模糊；书架内容区只保留可透出雨景的浅雾层，不回到不透明纯色页面。
- 顶栏与内容区共享同一张连续背景，不能在中间切成两块互不相关的色面。
- 封面本身承担主要色彩，页面控件保持浅雾灰绿，避免与背景争抢视觉重心。
