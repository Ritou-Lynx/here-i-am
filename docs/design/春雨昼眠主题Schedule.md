# 春雨昼眠主题 · Schedule

> 状态：双视图视觉与交互已确认并落 Flutter，等待真机观感验收。

## 数据边界

- 两个视图共用 Memory V3 中 `task / schedule / plan` 类型的活动卡片，不建立第二套日历数据。
- 有 `eventTimeMs` 的事项可以落到日历日期；没有明确时间的事项不能伪造日期，只留在待办视图的「未安排」分组。
- 点击事项仍进入 Memory Card Detail；完成操作仍更新同一张卡片的 active / completed 状态。

## 待办视图

- 按「已过期 / 今天 / 明天 / 本周 / 之后 / 未安排」组织。
- 顶部保留简洁概览，正文用高浓度局部浅雾卡片承载，不增加整页米白层。
- 已完成事项默认收起，用户需要时再展开。
- 已过期不使用突兀的红色，统一采用 Chat 动作色金黄 `#F2CA70`；浅色卡片上的小字使用更深的金棕保证可读性。

## 日历视图

- 在日程页面内部使用「待办 / 日历」局部切换，不增加生活空间顶级 Tab。
- 月历支持前后月份切换；日期格只用小圆点表达当天是否有事项，不在格内塞完整标题。
- 点击日期后，在月历下方展示当天事项清单；空日期使用紧凑空态。
- 「未安排」不硬塞进月历，日历底部只提示其数量，并引导回待办视图处理。

## 视觉约束

- 沿用 `assets/images/雨玻璃.jpg` 清晰全图背景，不模糊、不提亮、不压暗、不加全屏蒙版。
- 待办与日历是同一功能的两种呈现，切换控件紧邻页面内容，不与生活空间导航混成同一级。
- 日期格式统一为中文绝对日期；同一界面不混用「七月三十日」和 `7/30`。
- 「今天 / 明天 / 本周」等分组日期和月历下方的选中日期直接落在雨图时，使用暖象牙色与轻阴影，不额外增加标题承载条。

## Flutter 落地

- `CompanionSchedulePanel` 已提供待办 / 日历局部切换；状态保存在同一 `ScheduleViewModel` 生命周期内。
- 月历已支持前后月份、选中日期、事项圆点、当日清单与未安排回流。
- 待办保留紧迫度分桶、概览、完成切换、已完成折叠、下拉刷新和卡片详情入口。
