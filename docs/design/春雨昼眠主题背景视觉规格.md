## 构图锚点

- 整图为手机竖屏比例；**床只占底部约 15–20%**，窗、雨、绿叶占满上方大头。
- 左下保留台灯、蜡烛、书堆，作为暖光锚点与尺度参照，不被裁切、不被遮挡。
- 两侧白纱帘垂落，构成画面左右软边。
- 床上的被子读出**两个人并排躺着**的起伏；起伏的饱满端在画面中位、朝下冲着观众，读作身体 / 腿，脚朝向窗。

## 两人被子的处理

- 参考图（两人躺床俯拍）只取**胸口往下的被子**，去人头、去铁床架、去水印。
- 参考图透视与目标相反，**调转 180°** 后贴合：调转使鼓包离开底边，是后续裁切不切鼓包的前提。
- 用 photopea 自由变换 + 扭曲，把矩形裁块捏成上窄下宽、贴合原图斜躺床的梯形；四边擦成不规则垂落软边，破矩形贴片感。
- 右边缘缺口用仿制图章补满，再统一擦软。

## 色调与光线

- 参考图是阳光直射暖白，原图是阴雨暗冷灰；先**压高光、抬死黑**磨掉阳光味，再降饱和去暖黄、补冷调。
- 明暗方向靠**叠加渐变层（柔光 / 颜色模式、低不透明度）** 补：窗光自上、台灯暖自左；不靠均匀压暗（均匀调治不了方向光）。
- 边缘用软橡皮擦羽化，让被子与床面自然糊合。

## 工作流要点

- 床这块**全程 photopea 手工合成，不用 Stable Diffusion 重绘**。
- 原因见 ADR-1。

## 继承自旧设计的玻璃纪律

- 玻璃 / 雨滴表现须用**静态贴图**，禁止 canvas / `requestAnimationFrame` / `@keyframes` / 动画雨。
- 该纪律源自旧设计 ADR；载体已从「莫兰迪云 + 电流」换为「真实雨窗照片」，纪律本身保留。

## 储备素材（用途待定）

- 同视频、同卧室玻璃截取的**绿调雨滴纹理**：当前 Chat **无挂载点**——底图已含雨滴，再叠独立纹理是重复表达，且其绿调会染回已压掉的偏绿。
- 现状：已原样归档为 `assets/images/spring_rain_glass_texture_raw.png`（**未去色，不可直接当叠加层引用**）。
- 启用前处理：去色 / 大幅降饱和，仅留明暗纹理，方可作低不透明度叠加层；`_raw` 后缀即「未处理、勿直用」的护栏。

## 关键决策（ADR）

| # | 决策 | 否决备选 | 理由 |
|---|---|---|---|
| 1 | 两人被子用参考图贴图 + photopea 合成 | SD 局部重绘 | 重绘抽卡无法稳定产出「两人起伏」，且反复出裸体 / 杂物 / 偏绿；贴图结构确定、零随机、所见即所得 |
| 2 | 床占比靠「调转方向 + 裁底」压缩 | 纯裁切 / outpaint 扩窗 | 纯裁切必切鼓包（几何死结）；调转使鼓包离底、底部变无结构垂被，裁切安全；扩窗量大、翻车风险高且无必要 |
