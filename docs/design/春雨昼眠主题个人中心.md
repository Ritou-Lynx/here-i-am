# 春雨昼眠主题 · 个人中心

> 状态：2026-08-02 总页及分组次级页已确认并落 Flutter 首版；同日补齐应用级 UI Token 与图片生成独立次级页；User-truth JSON / CSV 导出能力仍待接入。

## 页面定位

- 个人中心是从 Chat 显式进入的固定用户入口，不放进生活空间同级 Tab。
- 页面只管理用户资料和应用级设置，不重复「关于林埃」中的角色头像、外观和角色 Voice ID。
- 不再把系统权限、模型配置、Agent 配置、Dev Room、普通设置和 Debugging 做成六个同级大入口。
- 总页使用单列分组导航，不增加顶部 Tab；设置搜索保留在右上角。

## 已移除的旧入口

- 个人中心不再显示旧「Agent 配置」入口；新版模型分配按用户任务呈现。
- 设置搜索不再返回旧 Agent 配置、旧 Memory 用户画像页或本地 Whisper 语音开关。
- Debugging 不再显示洞察模板展厅、本地语音模型删除、旧 Card 重处理、PKM 知识库重处理或评论重生成。
- `chat_agent` 不是当前 Companion 首页 Agent，也不在新版个人中心展示；其底层配置 ID 只暂时承担旧 ChatService 与未指定模型的自定义 Agent 兼容，待完成迁移后再删除代码。
- 小说与漫画的 Debug 入口在统一阅读前端真正落地前暂时保留，替代入口可用后同步移除，避免当前功能失去唯一入口。

## 总页结构

1. 用户资料：头像、昵称、账号和设备身份；统一由「编辑资料」进入。
2. AI 与模型：按聊天对话、记忆整理、日程分析、内容分析、游戏与角色扮演五类真实任务分配模型；模型服务和图片生成作为次级能力。当前 GameAgent 默认跟随聊天模型，但界面保留单独配置入口。
3. 声音与互动：语音输入、TTS 服务、媒体键和主动陪伴；林埃专属声音仍归「关于林埃」。
4. 设备与连接：系统权限、位置服务、专注限制、COROS、小红书、购物助手和玩具控制。
5. 数据与安全：完整备份、加密同步、User-truth JSON / CSV 导出、存储位置、隐私和删除账号。
6. 应用设置：语言、春雨昼眠外观、版本更新、版本与许可。
7. 开发与诊断：Dev Room、模型用量、异步任务、自定义能力、日志、索引和本机数据重置；放在页面底部并与普通设置明确分隔。

## 视觉规则

- 顶部使用清晰的 `assets/images/雨玻璃.jpg`，承载用户资料与编辑入口。
- 下方使用偏白偏黄的暖雾白 / 象牙米色连续内容层，不沿用「关于林埃」的大面积淡绿色；灰绿色只用于图标、开关和状态等小面积强调。
- 内容层圆角只出现一层，不露出重叠横线；禁止用大面积灰绿填充把个人中心整体染绿。
- 设置分组使用轻量列表行，不把每个入口做成独立悬浮卡片。
- 权限异常使用低饱和金色状态提示；危险操作只在最终操作行使用克制的灰红文字。

## Flutter 落地

- `PersonalCenterScreen` 使用 `雨玻璃.jpg` 顶部和暖雾白连续内容层，提供 AI 与模型、声音与互动、设备与连接、数据与安全、应用设置五组及底部开发与诊断入口。
- 个人中心已从 `CompanionLifeSpaceScreen` 同级 Tab 移除，改为 Chat 右上角更多菜单中的固定入口；Chat 头像仍只进入「关于林埃」。
- 模型切换页提供「按用途 / 按 Agent」双模式：用途模式以聊天、记忆整理、日程分析、内容分析和游戏与角色扮演五类任务批量写回相关 Agent；Agent 模式只列仍在运行的主路径与基础能力，可单独处理某个 API 额度耗尽或模型路径失效。游戏当前明确跟随聊天模型。
- Chat 右上角更多菜单提供高频「切换模型」入口，直接打开按 Agent 模式；个人中心 → AI 与模型仍保留完整入口。
- Agent 精细模式包含 Companion、Record Organizer、Companion Checkin、Schedule、Schedule Router、Media Analysis、Insights、Life Insights，以及 Memory Summary、Ask Resolution、Embedding；冻结或旧兼容的 PKM、Card、Chat、Comment 不重新暴露。
- 设置搜索同步改为上述用户任务分组，不再返回旧 Agent 配置或旧 Debug 总入口。
- 现有权限、位置、备份、同步、应用锁、外部连接和高级诊断页面均已接通；User-truth JSON / CSV 与账号删除目前只显示“待接入”，没有伪造动作。
- 个人中心向下打开的所有普通设置路由统一进入 `SpringRainUiScope`，从 `SpringRainUiTokens` 继承暖象牙背景、文字、表单、按钮、选择器、弹窗、Bottom Sheet 与 Toast；完整约束见 `春雨昼眠UI Token.md`。
- 图片生成不再跳回旧的全量 `SettingsPage`，改为独立页面，直接配置四种已实现后端及 OpenAI 兼容 / ComfyUI 的真实附加字段。
- 语言、外观、版本更新、版本与许可、语音播放、主动陪伴和隐私政策均已拆为独立页面；个人中心不再有入口打开旧的全量 `SettingsPage`。
- 外观页只展示当前唯一有效的「春雨昼眠」及其聊天 / 生活空间 / 设置三类场景规则，不再提供已废弃主题的选择器；历史保存的旧主题 ID 自动回落到春雨昼眠。
