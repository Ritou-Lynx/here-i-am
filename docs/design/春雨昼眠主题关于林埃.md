## 入口与边界

- 「关于林埃」从 Chat 中林埃的角色头像进入，不放进生活空间的同级 Tab。
- 用户个人资料仍是独立固定入口，不与角色资料或记忆系统混在一起。
- Memory Card 继续留在生活空间；本页只提供「你主动记录的内容」跳转。
- 原 Memory V3 Lab 的用户可读部分迁入本页；危险操作、原始数据和调试细节仍留在高级 Lab。

## 顶部角色区

- 标题和用户可见角色名统一为「林埃」，页面标题为「关于林埃」。
- 保留圆形角色头像位，以后支持上传图片；无头像时只显示静态图片占位，不响应点击。
- 外侧「编辑」进入林埃的头像、外观与声音设置；不再在页面下方重复设置板块。
- 顶部身份信息直接落在雨玻璃图片上，不使用与正文相似的淡绿色横条。

## 内容层视觉

- 使用 `assets/images/雨玻璃.jpg` 作为顶部背景，保持清晰、不模糊。
- 已确认保留下方连续的淡绿色内容承载层；不采用全图铺到底的对比稿。
- 内容层顶部为完整圆角，圆角两侧由图片承接，不能露出另一层直角横线。

## 记忆入口

- 「最近整理」位于绿色内容层内部，不跨越图片与内容层边界。
- 最近整理使用横向滑动卡片，默认展示最近三项，并露出下一张、显示页码和圆点反馈。
- 记忆名称对应关系：记忆碎片 = Fragment；我们的经历 = Episode；长期记忆 = Saga；最近想起 = Recall Log。
- 支持查看 Fragment，并保留重新提取记忆碎片、只凝结为我们的经历、重新检查长期记忆和完整整理等手动维护入口。
