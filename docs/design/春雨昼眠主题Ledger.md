# 春雨昼眠主题 · Ledger

> 状态：设计已确认并翻译进 Flutter，等待真机观感验收。设计严格基于当前共同账本的数据与交互，不新增不存在的统计口径。

## 真实能力边界

- 总账数据：真实收入、真实支出、现金结余、记录笔数。
- 分配数据：我的收入/支出份额、i 的收入/支出份额、i 的余额或欠款。
- 账目类型：`income`、`expense`、`transfer`，以及向后兼容的 `cost`、`reward`、`penalty`、`loan`、`repayment`。
- 每条明细包含：事项、总金额、i 的份额、我与 i 的分配或转账方向、发生日期、可选备注。
- 交互保持现状：下拉刷新、记一笔、长按明细后修改或删除。

## 页面结构

1. 顶部不再重复“共同账本”大标题和说明文字；生活空间分区导航已经说明当前页面。
2. 第一行只保留当前范围“全部记录”和紧凑的“记一笔”按钮。
3. 一张主摘要卡显示“真实收支结余”，下方并列收入、支出、记录笔数。
4. 两张较小卡片并列呈现“我的部分”和“i 的余额 / i 欠你的”，各自附收入分到与支出承担。
5. “最近明细”直接进入高浓度浅雾行卡；事项为主，日期与分配为次，金额右对齐。

## 视觉规则

- 继续使用生活空间清晰雨玻璃背景；没有整页米白层、背景模糊或介绍区。
- 主摘要、分配卡和明细行使用与 Memory Review 同源的高浓度暖灰绿浅雾，按信息层级调整面积，不另造新材质。
- 收入使用沉静苔绿，支出使用低饱和陶土色，内部转账使用暖金灰；颜色只辅助方向，正负号和文字仍承担语义。
- 金额使用等宽数字特性；日期统一为 `M月d日`，不使用斜杠格式。
- 「全部记录」与「最近明细」直接落在雨图上，使用暖象牙色与轻阴影；不为两个小标题增加额外蒙版。
- 卡片按压反馈与 Memory Review 一致；长按菜单、编辑表单和删除确认的结构本轮不改变。

## 暂不加入

- 不把“全部”伪装成本月数据；当前 ViewModel 读取的是全量总账。
- 不新增分类饼图、预算、趋势、搜索或月份筛选；这些需要单独的数据与产品决策。
- 不把 Memory Card 的消费模块复制成 Ledger 明细；Memory 是原始 User-truth，Ledger 是派生总账，入口与修正语义不同。

## Flutter 落地

- `CompanionLedgerPanel` 已移除重复大标题和说明，只保留「全部记录」与紧凑「记一笔」。
- 真实收支结余、收入 / 支出 / 笔数、我的部分、i 的余额或欠款和最近明细均使用局部高浓度暖灰绿浅雾卡片。
- 金额方向使用苔绿 / 陶土 / 暖金灰，日期使用 `M月d日`；原有下拉刷新、添加、长按修改与删除交互保持不变。
