# 春雨昼眠主题 · 生活空间外壳

> 状态：首版已落地，并于 2026-08-02 补齐雨图直出区域的小标题与操作控件可读性规则。

## 视觉目标

生活空间与 Chat 属于同一个「春雨昼眠」世界，但不是同一张场景照片：Chat 保留卧室雨窗，生活空间使用更抽象的雨玻璃，让数据页仍有安静、湿润的空间感。

## 背景纪律

- 背景使用 `assets/images/雨玻璃.jpg`，原图直接 `BoxFit.cover` 铺满。
- 不提亮、不压暗、不改色，不叠加任何全屏蒙版或全屏渐变。
- 背景始终保持清晰；顶部控件和内容卡片也不对其做背景模糊。
- 可读性只能由局部 UI 实体解决，不能反过来修改整张背景。
- `assets/images/spring_rain_glass_texture_raw.png` 仍是原始纹理素材，不直接用于页面。

## 公共外壳

- 顶部返回按钮与分区导航使用浓度稍高的半透明浅雾材质，但不模糊其背后的画面。
- 当前分区用浅暖灰绿胶囊标记；未选分区使用暖象牙文字与极轻阴影。
- 内容区不放整页米白承载层，雨玻璃直接贯穿卡片之间的留白。
- 浅雾材质只落在真实信息卡片上，并使用更高浓度保证文字可读；页面介绍性标题与说明不额外占据顶部空间。
- 直接落在雨图上的日期、分组名和小标题使用暖象牙色与极轻暗影；禁止使用深灰字，也不为了兜住标题再增加一层浅雾条。
- 同步、新建等真实操作可以使用独立的黄绿色浅雾按钮；它是可点击实体，不是标题背景。
- 系统状态栏与导航栏透明，图标使用浅色，背景保持连续。

## 真机验收关注点

- 背景是否在卡片之间完整、清晰可见。
- 顶部控件在最亮和最暗雨滴区域是否都清楚。
- 每张信息卡片的浅雾浓度是否足以承载深色文字。
- 五个分区名称在窄屏和英文环境下是否需要缩短或调整滚动导航。
- 底部系统手势区是否与内容滚动保持安全距离。
