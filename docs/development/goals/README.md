# 阶段 Goal 状态页

本目录保存已确认的阶段 Goal、工作包状态、集成记录和真人验收结论。协作生命周期以 `../COLLABORATION_EXECUTION_PROTOCOL.md` 为准。

## 规则

- Goal ID：`GOAL-YYYYMMDD-<slug>`。
- 用户确认前状态为 `候选`，确认并创建 Goal 后为 `活动`。
- 同一项目阶段默认只有一个活动 Goal；确需并行多个无关阶段时必须由用户明确确认。
- Goal 模式不会自动维护本文件；验收主窗在派发、阻塞、交付/集成及 Gate 结果改变时更新，相同状态轮询不写入。
- Goal 完成后保留文件，不删除或覆盖历史；新的阶段创建新文件。
- worker 不得修改其他工作包状态；整张状态表由验收主窗维护。

## 模板

模板字段按阶段实际需要选用；已有 Goal 的完成定义和真人 Gate 保留。文档/只读任务不因模板而新增构建或真人 Gate，普通多步任务不自动创建 Goal。新工作包可使用协作协议的简表，现有详细状态不批量迁移。
