# 本地听书音色真机赛马：用户操作手册

> 目标：不是选“网页样音最好听”的声音，而是选在 Here I am 的真实手机、真实长篇小说和常用语速下，听得久、跑得稳、仍然自然的默认音色。

## 0. 开始前由 i 准备

在让用户测试前，先实现 App 内“本地音色实验室”，至少提供：

- 同一测试稿、同一音量、同一语速下的匿名候选 A / B / C。
- 下载、暂停下载、校验和删除音色包，不要求用户手动搬模型文件。
- 一键播放短样和连续 20 分钟样本。
- 自动记录首句等待、生成耗时 / 音频时长比、播放中断、内存、温度和电量变化。
- 测试结束生成一份可复制结果，不要求用户看开发日志。

首轮候选：Kokoro v1.1 int8 的 6–10 个中文 speaker 先内部筛到 2 个，再与 MeloTTS、设备系统 TTS 组成最终三组。用户只测试最终 A / B / C。

## 1. 准备设备

先测主力手机，再测墨水屏：

1. 电量至少 50%，关闭省电模式。
2. 连接稳定 Wi-Fi，只用于首次下载模型；试听阶段会切到飞行模式验证真离线。
3. 使用平时听微信读书的耳机或扬声器，不临时换高品质设备。
4. 手机静置 5 分钟，让起始温度接近日常状态。
5. 音量调到日常听书水平，所有候选保持相同音量。

## 2. 下载候选

1. 打开 `设置 → 实验室 → 本地听书音色赛马`。
2. 依次下载 A / B / C；每个下载完成后必须显示“校验通过”。
3. 如果空间不足，页面会显示需要释放多少空间，不要去文件管理器手动拆模型目录。
4. 三个候选都准备好后切到飞行模式，重新进入页面；三者仍能播放才算真正本地。

## 3. 第一轮：盲听短样

不要先看模型名。每个候选按随机顺序听同一份约 2–3 分钟稿件，包含：

- 普通叙事。
- 两个人物的连续对话。
- 数字、日期、金额、英文名字和中英混读。
- “银行 / 行走、重复 / 重量、调查 / 调节”等多音字。
- 长句、破折号、省略号、引号和章节标题。

每个候选听完立即按 1–5 分评分：

| 项目 | 1 分 | 5 分 |
|---|---|---|
| 自然度 | 明显机器播报 | 接近真人平静朗读 |
| 耐听度 | 很快烦躁 / 累 | 愿意连续听一小时 |
| 停顿 | 经常断错地方 | 句意和呼吸自然 |
| 发音 | 多音字、中英混读常错 | 基本准确 |
| 人物感 | 对话和叙事完全一样 | 有轻微但不过度的变化 |

不要反复修改第一印象。第一轮结束只保留总分最高的两个候选。

## 4. 第二轮：常用语速

对剩下两个候选分别试听：

1. `1.0x`：判断原始自然度。
2. `1.25x`：日常听书候选速度。
3. `1.5x`：判断加速后是否吞字、发尖或节奏破碎。
4. 如果平时常用其他速度，再加那一个；不要同时测试十几个档位。

默认音色必须在常用速度下好听。只在 1.0x 好听、1.25x 就明显崩坏的声音不能当默认。

## 5. 第三轮：主力手机长听

在三星主力手机上对两个候选各连续播放 20 分钟：

1. 前 5 分钟停留在阅读器，看当前句高亮和滚动是否跟上。
2. 接着锁屏 5 分钟，用锁屏按钮暂停、继续、快退。
3. 再切到其他 App 5 分钟，确认后台不断播。
4. 最后接一次通知 / 导航提示或插拔耳机，确认音频焦点恢复合理。
5. 暂停后划掉 App，再打开，检查是否最多回退到当前句开头。

结束时只回答三个主观问题：

- 手机是否明显发热？
- 你是否开始觉得音色单调或烦躁？
- 如果这是一本 20 小时的书，你愿不愿意继续用它听？

客观耗时、温度、电量和内存由实验室自动记录。

## 6. 第四轮：墨水屏兜底

在 MEEBOOK 上重复 10 分钟，不要求它和三星一样快，只检查：

- 首句等待能否接受。
- 生成速度是否持续追得上播放速度。
- 翻页 / 滚动是否因 TTS 推理明显卡顿。
- 锁屏和恢复是否稳定。
- 设备是否快速发热或被系统杀掉。

如果 Kokoro 在主力手机胜出但墨水屏跑不稳，结论不是放弃 Kokoro，而是“主力默认 Kokoro + 墨水屏自动建议轻量 MeloTTS / 系统 TTS”。

## 7. 决策规则

默认音色需同时满足：

- 飞行模式可用。
- 常用语速自然度和耐听度均不低于 4/5。
- 主力手机连续 20 分钟不掉队、不中断、不过热。
- 首句等待可以接受，之后靠预生成没有明显句间空洞。
- 错读不是高频到破坏理解；少量 bad case 可进入后续发音词典。

若主观最好听和性能最好不是同一个：主力默认优先耐听度，低性能设备优先稳定性。音色始终允许用户自行切换，不把赛马结果做成不可更改的唯一答案。

