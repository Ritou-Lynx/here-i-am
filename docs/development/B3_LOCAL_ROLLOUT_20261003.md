- nullable 排序列由 schema 60→61 迁移；仅源定义变动后运行 build_runner，不手改生成代码。
- 专用安装脚本保留默认分支保护，绑定 codex 候选 HEAD/无未跟踪构建输入/现有 APK SHA256，并在任何手机操作前校验 APK 包名；签名文件留本机并忽略。
