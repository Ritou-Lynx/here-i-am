## 为什么仍不能直接同步

历史净化在保留公开仓库链接、作者/日期/说明和拓扑的同时改变了提交 SHA。旧开发线包含大量私人提交、分支和未提交状态，公开线则是重新生成的作品集历史。README 美化本身不是障碍，真正的边界是两个不相交的 Git 谱系。

后续必须从净化版副本出发，按文件或工作包移植当前有效源码。不能把旧 `.git` 覆盖过去，不能强推旧线，也不能把两个根历史直接 merge。公开 README、截图和作品说明继续保留；私人数据库、签名、求职证据、运行日志和公开源码分开处理。

4. **保持 Goal 1 的既有收口路径。** 工作电脑备份未发现额外业务代码，不需要扩张 Goal。先完成普通入口独立数据/后台装配，再冻结同一候选做任务执行、停止、正常/异常重启恢复与清理真人 Gate。
