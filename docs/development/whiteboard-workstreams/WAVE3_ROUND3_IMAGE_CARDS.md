# Wave 3 真人验收 Round 3：图片主卡与卡片库删除交接

> 分支：`codex/whiteboard-wave3-round3-image-cards`
> 基线：`b81ba1cf`
> 拥有范围：W1/W2 卡片呈现、完整图片查看、卡片库 UI；不含 ingestion、视频、schema、依赖、W5/Bridge。

## 已实现

- RichText 首个有意义块为图片且不存在可编辑文字时，判定为“图片主卡”；画布以图片占约 80%–100%，底部最多一行标签或文件名元信息。文字中嵌图仍保持既有混排卡面和富文本编辑。
- 图片主卡双击/从卡片库打开后进入整图适配缩放查看，不再伪装成不可编辑的正文；下方保留真实 Card 标签管理并即时保存。
- 卡片库增加明确“全局删除”入口。二次确认会区分未上板与已上板：全局软删不移除 BoardItem，所有既有放置诚实变成失效引用；失败保留卡片并提示重试。
- 修复纯本地图片 `sourceType == null` 时卡片库 `_sourceTypeLabel(hit.sourceType!)` 强解包导致的红底黄字 ErrorWidget。无 Source 的图片现在显示稳定“图片”类型；缺失/损坏对象继续显示克制占位并保留删除入口。
- 画布图片模式解析由带 `cardId + updatedAt` 失效条件的 Stateful Future 缓存承载，平移/缩放 rebuild 不会每帧同步读 RichText 文件。

## 验证与恢复

- 新增/扩展 15 条本地媒体回归：无 Source 图片、图片主卡比例与单行元信息、混排编辑、整图查看与标签保存、重启/多 BoardItem、缺失对象、损坏文档、全局软删已上板语义及删除失败恢复。
- 卡片库、本地媒体、完整编辑器、画布直接交互与性能最终联合回归 **62/62**；500 卡冷加载约 6.6ms，既有性能守门未回退。
- 5 个变更/测试 Dart 文件定向 analyze 零问题；未触网渲染，未新增依赖/schema，未运行 build_runner，未 push。
