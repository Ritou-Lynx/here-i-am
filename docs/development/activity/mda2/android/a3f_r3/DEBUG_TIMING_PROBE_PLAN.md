# A3F-R3 剩余时序项的 Debug 验证支持

2026-09-28；W0 在原 Goal 范围内继续验收。9A099611 的 H1/H2 原生终态到前台页面同步分别取得保守 775ms/515ms 的设备证据；剩余为逻辑立即 checking、无有效状态回复时 3 秒 unknown、真实迟到回复交付后的拒绝与完整投影尾段。

## 范围与候选

此前“无新增 APK 埋点”描述的是 9A 同包只读取证方案。现已确认只读 VM 采样不能严格证明状态赋值顺序，也无法触发 App 内部读取延迟。W0 在用户已授权的实现与继续验收范围内新增最小 Debug 验证支持，保留原完成标准，不新增产品功能或正常采集入口。新候选须另存源码 manifest、APK hash、验证和设备结果；不得继承 9A 的真人通过结论。

复用隔离工作树 `a3f-r3-w0-integration`，基线 `b2adc44b7c04983a931c39695b81491cd295084b`。实现包 `/root/r3_timing_probe_impl`（GPT-6 Astra / high），只拥有诊断 Dart 入口、诊断 helper/controller/screen、collector 可选纯观察 hook 与专项测试。W0 负责独审、构建、设备与共享文档。worker 不操作设备、不构建、不提交、不派生。

## 最小实现

- 唯一真实 MethodChannel platform 外包透明装饰器，完整委托 signal/delivery/observation/outboxLease 四接口；不增加 channel、原生方法或 wire 字段。
- 用户或已获授权的自动操作显式开启最长 180 秒的内存记录，再选择一次 manual-refresh 或 resume 读取注入。默认关闭；周期 poll、只读 observer、推送、开始/停止/释放不消费注入。
- 只对选中的读取链使用一次性 Zone 标记，getter 进入且尚未 await 时消费；周期 Timer 在 Zone 外创建。已有 pending 按原逻辑合并并如实标记未触发，禁止强制取消/重试。
- 先取得真实解析的不可变 native 状态，再异步延迟 20 秒，原样交付同一对象一次。此长度覆盖自动通知导航；3 秒业务 timeout 保持原样。取消或销毁不得伪称业务守卫拒绝。
- 单调时钟、固定容量、有序的内存 trace 记录动作入口、checking 赋值、每次投影发布、请求开始/真实捕获/交付、实际接受/拒绝。只输出固定码、有限整数和内部比较布尔；不含原始身份、owner、nonce、路径、key、事件正文或异常正文。
- trace 默认不落盘、不联网；只读 service extension 仅在 Debug 诊断入口注册。溢出、缺序、回调错误或未封口均为证据不完整。观察回调不得改变正常处理。

## 验证矩阵

| 项目 | 成立条件 | 失败或不完整条件 |
|---|---|---|
| 立即 checking | 动作入口、赋值、投影发布在同一读取开始之前，同一单调时钟 | 只有间隔采样或动作提交收据；不要求至少渲染一帧 |
| 3 秒 unknown | 真实 getter 捕获但未交付，期间没有其他有效状态回复；实际 unknown 投影上界 ≤3000ms | 超出 3000ms 保留 RED，不加容差；推送提供有效状态时不能冒称无回复 |
| 迟到回复 | 真实 running 捕获、同代终态、旧回复实际交付、原守卫实际拒绝，封口 trace 内无旧回复引发 ready | 取消/丢弃未交付、跨代混算、缺失投影事件 |
| 透明性 | 四接口委托、默认关闭、poll/observer/push 不受影响、Timer Zone 隔离、pending 合并 | 为取证阻断正常推送或轮询，伪造 native 状态 |
| 记录边界 | 到期封口、显式结束、容量/序号/错误检查、无敏感字段 | 溢出后继续宣称完整；持有回复未结束即宣称已验证拒绝 |

3 秒 timeout 结束后，新鲜 poll 可能合法恢复 running/ready；它与 20 秒旧回复必须按本地请求编号区分。通知自身停止通常命中 terminal/revision 守卫；页面 stop 的 generation 守卫是另一场景，不互相代填。H1/H2 原生起点仍由既有独立 observer 见证，不用 Dart 推送到达时间替代或混算两条时钟。

每次构建前 critical checks；新候选独立存放，旧 9A APK/输入/失败收据不覆盖。设备操作前核对精确安装包、锁屏、连接及资源；结束恢复 E1 正式包、原绑定 BLE、诊断持久记录，并清理本轮调试连接。手机断开只阻断设备部分，源码与专项验证继续。
