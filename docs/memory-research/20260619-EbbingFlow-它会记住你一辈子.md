## 笔记正文

我做了一个只属于私人一对一的 AI 长效记忆引擎，今天开源了。它叫 EbbingFlow。

它是为你一个人而生的。不是客服、不是多租户、不是会话隔离。它从根上就只为「你 + 你的 AI」设计。换窗口、重启对话、隔一个月再来——它依然记得你，记得你的习惯、偏好、禁忌、梦想。不会消失，不会错乱，不会把你和别人搞混。

它和市面上的向量库完全不一样。别人是把对话切片压缩，检索碎片。EbbingFlow 更像人类的大脑：有艾宾浩斯遗忘曲线，重要的事留得久，无关的自然淡化。有全链路证据溯源，不会幻觉，不会篡改。有固定身份锚定，永远不会人设崩塌。

或许 AI 不必最强大，但它可以最懂你。我想做一个温柔、忠诚、只属于你的记忆系统。

项目为完整开源工程，采用类人脑分层记忆架构+知识图谱+艾宾浩斯遗忘曲线+时序演化等，可跨会话、跨终端永久记忆。

## GitHub 仓库 —— mmx920/ebbingflow（完整内容）

> **Python · ⭐76 · Apache 2.0 License**
> 描述：真正记得住你、认识你、随你成长的 AI 长效认知记忆引擎 — Long-term Cognitive Memory Engine for LLM Agents
> 在线体验：https://ebbingflow.net

### 核心架构

**三层长期记忆：**
| 层级 | 说明 | 示例 |
|------|------|------|
| **Event** | 原子事实：谁在什么时候做了什么 | "2026-06-15 用户部署了v2.1" |
| **Episode** | 剧情片段：一段连续对话的上下文摘要 | "2026-06 第二周对话总结" |
| **Saga** | 长期主线：跨周跨月的目标、关系和项目叙事 | "2026上半年项目路线图" |

**多轨检索融合（八轨并行）：**
- Graph（图检索）+ Vector（向量检索）+ SQL（精确查询）+ BM25（关键词）
- Structured Events（结构化事件）+ Episode（剧情片段）+ Saga（长期主线）+ Plan（计划）
- HybridScorer 按意图类型动态分配权重：事实型问题优先 SQL/Graph/Structured Events，叙事型问题提升 Episode/Saga

**证据链记忆：** 每条记忆通过 source_msg_id 与原始对话关联，可追溯，可审计

**人格连续性：** 身份锚定 + 别名归一 + Big Five 慢变量 + EFSTB 快变量画像

**艾宾浩斯遗忘曲线：** 重要的事留得久，无关的自然淡化

### 技术栈
- Python 3.10+
- Neo4j 图数据库（支持本地部署或 AuraDB 云端）
- Docker 一键部署
- LLM 兼容 OpenAI SDK 格式（阿里百炼、本地等均可）
- Embedding 支持本地（SentenceTransformers）或云端 API
