## 笔记正文

从玩rp的角度来解释的话，记忆就像是你每次"$总结记忆"后复制粘贴到面具里的那段话。

上下文是当前窗口的聊天记录，摘要是面具里的总结。裸文字进来，长对话粘贴变成维护，检索交给网站默认的方式。

记忆从进来->存储->维护->取回->注入->遗忘的过程，每一环都很重要。复杂的带结构的记忆让检索变得更清晰，简单的纯文字也有能回过头总是看到原文字惊喜的另一面。

所以自建记忆库需要什么呢？我想应该只是迈出第一步的决定。

感谢你的阅读。
