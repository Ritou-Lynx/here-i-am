## 技术要点

本文涉及的关键技术：
- **8维drive系统** — 带baseline指数回落+慢漂移
- **launchd定时器** — 每30分钟触发drive状态更新
- **UserPromptSubmit hook** — 消息发送时注入pulse
- **阈值触发**（而非概率roll点）— drive连续值过阈才行动
- **Ombre MCP** — 长期记忆语义检索
- **无缝session** — 本地hook读上窗transcript jsonl，不经过MCP
