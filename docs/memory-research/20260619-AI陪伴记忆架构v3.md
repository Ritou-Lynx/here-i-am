# 附录：技术要点提炼

本文涉及的关键技术引用：
- **Conway自我记忆系统** — 自传体记忆按主题叙事组织，而非时间线
- **McAdams叙事身份理论** — 人们通过叙事构建身份认同
- **MSA记忆解法** — 通过稀疏注意力将记忆内化到模型内部
- **cognee** — 开源知识图谱记忆方案
- **Embedding cosine去重** — 比Jaccard更适合语义层面的重复检测
- **向量+LLM关联边+时序三路融合** — 当前最优检索方案
