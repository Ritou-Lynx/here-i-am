# 记忆方案调研

目标：综合对比多个 AI 记忆方案，为 Here I Am 设计最适合的记忆架构。

## 核心原则

**数据组织以 AI 可操作性为第一优先级。** 用户不关心底层沉淀成什么格式的文档或怎么组织，只关心最终体验——卡片好看、聊天能召回。评估方案时，"LLM 好不好读写检索"的权重高于"人类看着是否整齐"。

## 评估维度（最终对比时使用）

- AI 可操作性（最高权重）：LLM 读写检索的便利程度
- 用户体感：用户是否需要管理底层数据
- 记忆准确性：过时信息如何更新、冲突如何解决
- 检索召回：角色聊天时能否精准找到相关记忆
- 跨记忆关联：不同事实之间的关系如何表达
- 隐私分层：角色私密记忆 vs 用户事实记忆的边界
- 可扩展性：未来接入更多数据源的难度
