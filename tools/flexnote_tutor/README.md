# FlexNote 学习导师（任务单 A）

让 Codex（用 ChatGPT 订阅登录）通过 FlexNote MCP 把知识库当学习资料：从资料现出新题、讲评时引用出处，并把薄弱点写回 FlexNote。用到的工具基于 FlexNote 1.1.56 的 MCP 工具清单。

## 一次性设置

1. **FlexNote**：设置 → AI 助手设置 → MCP 服务，打开服务，**重置访问令牌**，然后复制"Codex CLI"标签页里的配置，按它的说明粘贴到 Codex 的配置文件里。FlexNote 退出后 MCP 服务也会停止，所以学习时要开着 FlexNote。
2. **学习目录**：在你电脑上建一个**不在本仓库里**的目录，比如 `~/study`，把这里的 `STUDY_AGENTS.md` 复制进去并改名为 `AGENTS.md`，再把 `subjects.md` 也复制进去（模板不直接叫 AGENTS.md，免得在仓库里干活的 Codex 误读）。以后在这个目录里启动 Codex，它会自动读 `AGENTS.md`。
3. **教综资料**：把山香教综的拆解资料导入 FlexNote 的"求职"空间，见下文。
4. **首次学习**：在 FlexNote 里打开"求职"空间，然后在 `~/study` 里启动 Codex，说"初始化教师编"。它会先列出要建的标签、属性列和白板，你确认后再建。

## 教综拆解资料怎么导入

按资料现在的格式选：

| 现在的格式 | 做法 |
|---|---|
| Markdown 文件夹或 Obsidian Vault | 用 FlexNote 自带的导入（保留文件夹结构和双链）。这是最省事的方式 |
| 思源笔记 | 用 FlexNote 的思源导入（通过本地 API，保留笔记本层级） |
| PDF | 直接拖进 FlexNote 建成 PDF 卡。AI 检索时可以按页定位 |
| Word 或其他格式 | 先转成 Markdown 再导入；也可以让 Codex 读本地文件，按章节用 `create_note_card` 逐章建卡 |

导入后，把位置（白板名或收藏文件夹名）填进 `subjects.md` 的"资料位置"。

注意：这份拆解来自有版权的教材，只放在你本机和 FlexNote 里，**不要放进 GitHub 仓库**。

## 怎么用

在 `~/study` 里启动 Codex，直接说就行：

- "今天学教综，练一轮"
- "讲一下德育原则，然后考我"
- "把认知发展理论几个流派串起来"
- "复盘一下这周"
- "结束"（它会写学习记录卡、更新掌握度、在日记里追加一行）

## 已知限制

- MCP 只能操作 FlexNote **当前打开的空间**。学之前要先在 FlexNote 里切到对应空间。
- MCP 服务只在本机 `127.0.0.1` 上，所以只能在电脑上用 Codex 学。手机上可以用 FlexNote Android 版查看卡片和学习记录。
- 语义检索会消耗智能索引点数（主要在建索引时消耗）；关键词检索不消耗点数。
