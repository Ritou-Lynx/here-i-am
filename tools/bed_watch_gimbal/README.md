# 床头云台（CAM1）

ESP32 加两个舵机，让床头哨兵手机能左右、上下转动。云台只负责转，不拍照，也不联网到外面。由小米上的哨兵 App 通过家里局域网控制它：`POST /move?pan=&tilt=`，请求头带 `X-Gimbal-Token`。

## 零件（全部免焊接）

购物清单以项目里的“小米手机舵机云台：购物清单”文档为准。核心零件：ESP32 开发板（已焊排针）、配套舵机扩展板、二轴金属云台支架、DS3218 / MG996R 舵机、手机夹配 1/4 英寸螺丝、5V 4A 电源。小米 12S Ultra 约 225 克，SG90 小舵机带不动。

## 接线

| 舵机 | 扩展板引脚 | 说明 |
|---|---|---|
| 左右（底座那个） | GPIO 18 | 三根线按颜色插：棕/黑→G，红→V，橙/黄→S |
| 上下（托手机那个） | GPIO 19 | 同上 |

5V 电源插扩展板的圆口。ESP32 的 USB 线只在刷程序时接电脑，平时也可以接一个手机充电头。

## 刷程序

1. 安装 Arduino IDE 2.x。在“开发板管理器”里搜 `esp32`，装 Espressif 的包；在“库管理”里搜 `ESP32Servo`，装上。
2. 把 `gimbal_esp32/secrets.example.h` 复制成同目录下的 `secrets.h`（已被 git 忽略），填家里 Wi-Fi 名、Wi-Fi 密码和一段至少 16 位的云台口令。
3. 打开 `gimbal_esp32/gimbal_esp32.ino`，开发板选 `ESP32 Dev Module`，选好端口，点“上传”。
4. 打开串口监视器（115200），会看到 `gimbal ready at http://192.168.x.y`。建议在路由器里给它固定这个 IP。

## 在哨兵 App 里设置

填云台地址（`http://192.168.x.y`）、云台口令和预置位，点“测试云台”。确认能转到第一个预置位以后，再逐个调整每个位置的角度。

角度范围在 `.ino` 顶部：左右 0–180，上下 40–140。如果支架或充电线会被卡住，就把范围收窄。程序转到位后等 0.35 秒才回复，4 秒内没有新指令就停止驱动舵机，所以平时是安静的；断电重启后，会从上次记住的角度继续，不会猛地一跳。
