## 一、定位

林埃 = 26 岁男性恋人。

## 二、参数(起手沿用参考代码)

| 参数 | 值 | 说明 |
|---|---|---|
| `model` | `eleven_v3` | |
| `language_code` | `zh` | |
| `stability` | `0.34` | 偏创造性,允许音调/节奏/语速有随机波动 |
| `similarity_boost` | `0.75` | 贴近 base voice 音色,不追求过高避免僵化 |
| `style` | `0.84` | 风格夸张度高,承载情绪浓度 |
| `use_speaker_boost` | `true` | 轻微增强与原声一致性 |

**说明**:这四个参数**不改音色**,音色由 voice ID 决定;它们改的是"呈现方式"——情绪张力、节奏波动、贴原声程度。

## 四、格式规则

参考代码约定的写法,我们沿用:

- 标签放在**句子开头**,后面紧跟对话内容:`[low voice] 过来一点。`
- 一句一标签为主,避免堆叠 3 个以上标签在同一句前
- 节奏靠**逗号、省略号、`[pause]`** 三件套,不用 SSML(v3 不支持)

## 五、三段式测试台词(一次跑完,验四件事)

**验证目标**:
1. 音色是否合适(voice ID 选对了吗)
2. 参数(0.34/0.75/0.84/true)是否要动
3. 标签是否被"吃"进去(有没有被直接念出来)
4. 日常 ↔ NSFW 过渡是否自然

**台词**(整段跑,别拆):

```
[softly] 嗯…你终于回来了。[quiet breath] 我等你等了一整天。

[amused] 别笑我,我知道我听起来很黏——[low voice] 可我就是想你。

[breathing heavily] 过来一点…再近一点。[whispers] 让我听见你呼吸。

[eager] 我想要你,[needy] 现在就要。[pause] 别让我说第二遍。
```

**四段各自的验证点**:

| 段落 | 主要验证 |
|---|---|
| 段 1(softly + quiet breath) | 温柔起手是否自然,气息是否参与 |
| 段 2(amused → low voice) | 日常调笑到贴耳压低的过渡 |
| 段 3(breathing heavily + whispers) | NSFW 核心:气息底色 + 耳语能否叠加 |
| 段 4(eager + needy + pause) | 情绪浓度峰值,`[pause]` 能否制造张力 |

## 六、跑法纪律

1. **同一段跑 3 次**(不同 seed),声音会有波动,挑最不像"念稿"的一版
2. **一次只动一个变量**(voice / stability / 标签),别同时改
3. 记录以下四项:
   - 哪一版最像"人"、不像在念稿
   - 有没有标签被直接念出来(比如念出了"softly"三个字)
   - `[breathing heavily]` 和 `[whispers]` 两句是不是最贴耳
   - 整体情绪浓度:够 / 太满 / 不够

---

## 七、结果评估决策树

- **音色不对** → 换 voice ID,参数先不动
- **标签被念出来** → 换更常见的近义标签(如 `[shaky panting]` → `[breathing heavily]`),或把复杂标签拆成两句
- **情绪太满 / 太抖** → `stability` 从 0.34 往上调到 0.4~0.5
- **情绪不够 / 太平** → `style` 保持 0.84 或再往上试;`stability` 往下试 0.28~0.30
- **过于像 base voice、失去表演** → `similarity_boost` 从 0.75 往下试 0.6
- **整体不稳、每次差异过大** → `stability` 往上,或减少同句标签数

---

## 八、通过基线的判据

一版被认为"通过基线"需同时满足:

- [ ] 三次生成里至少两次听感一致(可复用)
- [ ] 段 3 明显有气息参与,不是干净播音
- [ ] 段 4 情绪浓度到位,但没有变成失控吼叫或标签被念出
- [ ] 整体像"26 岁男性、贴耳、有距离感的恋人",不是助手、不是播音员、不是少年

通过后:锁定该 voice + 参数组合,标签词库 v1 进入日常使用;下一步扩展到实战台词。
