# 白板工作台 MVP

这是 Here I am 白板桌面端的第一条可用纵切，不是最终白板引擎选型。它使用一个可替换的 DOM 画布适配层，先验证稳定的数据边界和核心使用路径：

1. 在高密度工作台查看生活、阅读、任务、记忆、健康和账本模块。
2. 进入唯一的卡片库，按类型筛选或搜索卡片。
3. 新建并打开白板。
4. 从卡片库拖入卡片，移动、缩放或移除卡片摆放。
5. 保存白板、卡片摆放和视口；刷新或重启本地服务后恢复。

## 启动

需要 Node.js 20 或更高版本，无第三方依赖。

```powershell
cd desktop\whiteboard_mvp
npm start
```

打开 `http://127.0.0.1:4178`。

## 验证

```powershell
npm test
node --check src\app.mjs
node --check src\model.mjs
node --check server.mjs
```

## 当前边界

- 首页数据是明确标注的结构示例，尚未接入 Flutter/Drift 中的真实生活数据。
- 林埃悬浮对话已具备界面与当前页面锚点，但尚未接入执行 Agent。
- 视频播放器、字幕时间轴、任务房间和记忆压缩不在这条纵切内。
- 白板引擎仍需按既定赛马文档选择；`src/model.mjs` 的 `Card`、`Board`、`BoardItem` 和 `viewport` 是需要保留的稳定边界。

视觉遵循白板组件规范 v0.2：以 `#F0EFEB` 中性纸灰和墨色建立页面层级，Palm 绿只负责动作、活动态与主数据，琥珀只负责单一焦点或警告；无常驻顶栏、低圆角、可完全收起侧栏、正式植物 `i` 品牌符号、媒体主导卡片预览，以及 Huiwen Mincho/Cascadia Code 的本机字体回退。

当前卡片库按钮明确写作“放入最近白板”，对应这条纵切的临时行为。正式交互将打开目标白板选择器，提供最近白板、全部白板搜索和新建白板；选择目标后只新增 `BoardItem`，不会复制 Card。
